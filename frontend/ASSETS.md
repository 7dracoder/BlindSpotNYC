# Browser tab logo

The BlindSpot NYC logo is used only by the favicon link in `index.html`. It does not appear in the app header, inspector, map controls, or any other page section.

- Original generated PNG: `public/blindspot-logo.png`
- Optimized browser favicon: `public/blindspot-favicon.png` (64 × 64 PNG, with transparency preserved)
- Generation: built-in image generation tool, September 27, 2026.
- Export: the generated image was copied into this project and downscaled with macOS `sips` for the browser favicon.

## Generation prompt

> Use case: logo-brand. Asset type: a single square browser favicon for BlindSpot NYC, an NYC building-risk map. Create a polished, extremely legible compact monogram mark: a bold amber-orange capital B whose geometric silhouette subtly incorporates the facade of a city building and a single dark window cutout suggesting a blind spot. Put the amber mark on a solid near-black rounded square tile, filling most of the square with generous clean edges. Flat, precise, vector-like artwork with crisp simple contours that reads clearly at 16 and 32 pixels. Palette matches the app: amber #f59e0b and near-black #141210. Transparent area outside the rounded square. Centered icon only. No words, no slogan, no mockup, no photographic texture, no shadows, no decorative border, no extra objects. This logo will be used only as the browser tab/favicon, not in the app body.

Tool setting: `transparent_background: true`.
